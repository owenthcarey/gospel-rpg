# Baseline and next milestones

Implemented: an explorable village, original GLBs, a Blender-authored traveler walk cycle, A* and keyboard movement with route markers, camera controls, four characters, a complete main quest, Ezra’s optional exploration story, three discoveries, authored dialogue, journal, satchel, navigable map, autosave/manual slots, versioned import/export, optional ambience, responsive menus, reduced motion, quality controls, tests, and a gated release workflow.

Next:

1. Expand the traveler’s rigid limb walk cycle into skeletal animation; add NPC walk/idle cycles and boat/net interactions.
2. Add the catch-and-calling sequence after narrative and theological review.
3. Refine terrain, water, crowds, sound, and interaction affordances.
4. Introduce a region registry and save migration for travel.
5. Profile mobile GPUs, then implement region-aware offline caching and updates.

Before public production release: historical/editorial review, real Safari/iOS/Firefox/Edge/Android testing, broader accessibility (including nonvisual navigation), storage quota/eviction testing, an explicit project license, versioned save fixtures, and a maintained compatibility policy.

This is a tested vertical-slice foundation, not the complete multi-region RPG.
